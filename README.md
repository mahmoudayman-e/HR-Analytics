# HR Analytics Interactive Dashboard (Power BI)

## 📌 Project Overview
This repository features a comprehensive, 3-page **HR Analytics Dashboard** built using Power BI. Designed with a modern, data-driven dark theme, this dashboard transforms raw human resources data into actionable insights. It empowers HR executives and business leaders to monitor workforce demographics, track employee performance, optimize compensation strategies, and audit granular employee records.

---

## 📊 Dashboard Pages & Features

### 1. Overview Page (Workforce Demographics)
<img width="1198" height="672" alt="Overview" src="https://github.com/user-attachments/assets/f37ad41f-15fd-4e0b-a6dd-438588d8c0cf" />

Provides a high-level summary of the organization's current workforce status.
* **Key Metrics (KPI Cards):** Displays Total Headcount (1,766 employees), Median Salary ($95K), Total Sick Days (12K), and Total Departments.
* **Salary Distribution:** Breaks down total payroll spending by employee groups and contract types (Full-Time vs. Part-Time).
* **Departmental Headcount:** An interactive heatmap grid showing staffing levels across various business departments and locations (Houston, Los Angeles, New York City, Seattle).
* **Historical Trends & Education:** Tracks hiring trends over time (2013–2018) and visualizes the workforce's educational background (Bachelor, Doctor, College, Masters) using a donut chart.

### 2. Performance & Workplace Insights Page
<img width="1199" height="675" alt="Assessment" src="https://github.com/user-attachments/assets/65c7a609-27ee-4725-8a05-0581fd5493d2" />

Focuses on employee health, satisfaction, and operational metrics.
* **Performance Distribution:** A horizontal bar chart segmenting the workforce by performance tiers (Low, Good, Excellent, Outstanding).
* **Workplace Well-being:** Analyzes qualitative employee attributes including Work-Life Balance and Job Involvement levels.
* **Compensation vs. Age:** A scatter plot tracking the correlation between the Average Salary and Employee Age to identify potential wage gaps or structural trends.

### 3. Employee Details Page (Data Audit)
<img width="1193" height="670" alt="Details" src="https://github.com/user-attachments/assets/6313c3f8-182a-4a3b-9338-0251e8100cdf" />

A granular, tabular view for direct data exploration and individual compliance auditing.
* Displays complete row-level records including Employee Names, Job Types, Marital Status, Performance Ratings, Salaries, and Years in Current Roles.

## 🛠️ Technical Toolkit & Skills Demonstrated

* **Data Engineering & ETL:** Used **Power Query** to clean raw HR data, handle missing values, and transform qualitative strings (e.g., performance ratings) into structured, report-ready attributes.
* **Analytical Modeling (DAX):** Authored custom measures and aggregations to calculate core business metrics like Medians, Counts, and running Averages.
* **Advanced Data Visualization:** Structured an intuitive UI layout utilizing strategic visual hierarchies, unified color mapping, and a cohesive dark UI skin.
* **Interactive UX/UI Elements:** Integrated responsive cross-filtering, multi-select slicing controls (by Gender, Location, Status), and tabular page navigation buttons (Overview / Assessment / Details).
